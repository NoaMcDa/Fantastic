Fantastic · Design System · 06

Buttons

One gold button per screen — the thing we want the user to do next. Everything else steps down to a grey surface or plain text. Labels are verbs in Hebrew, never nouns.
Hierarchy
hover and press are live
Primary — accent/500 on dark label. One per screen.
Secondary — surface/raised + hairline. Parallel choices.
Tertiary — text only. Dismissals, “skip”, inline links.
Destructive — danger tint; fills solid red only while pressed.
