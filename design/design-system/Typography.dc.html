Hebrew rules
Hebrew has no uppercase — emphasise with weight and colour, never with caps or tracking. Letter-spacing stays at 0 for all Hebrew; positive tracking breaks the letterforms apart. Line-height runs one step looser than Latin at the same size.
Minimums
13px is the floor for any text a user must read; 12px labels are permitted for Latin overlines only. All type scales with Dynamic Type — layouts must survive a 130% text size without truncating a number.
