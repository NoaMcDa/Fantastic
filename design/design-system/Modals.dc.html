Modal states

Four ways the app interrupts, in descending order of how much it is allowed to: a sheet the thumb can reach, a dialog that blocks, a processing state that must not lie about its length, and a toast that never asks for anything.

Rules
One modal layer at a time — a sheet never opens another sheet. Anything reversible is done immediately with an undo toast instead of asking first; only losing data earns a dialog. Every modal returns focus to the control that opened it, and closes on the hardware back gesture.
