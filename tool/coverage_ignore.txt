# tool/coverage_ignore.txt — gated files lcov correctly emits no record for.
#
# `flutter test --coverage` writes an `SF:` record only for files that contain
# executable statements AND are imported by some test. The files below are the
# first kind of absence: there is nothing in them to execute, so no test could
# ever cover them and lcov is right to stay silent.
#
# This list exists because `tool/check_coverage_files.sh` cannot tell that
# absence apart from "nobody wrote a test". Every entry is reviewed on the way
# in — if a file here ever grows a method body, a constant with an initialiser,
# or an enum with fields, it stops being declaration-only and must come off.
#
# Reviewed against the tree at the M4/M5 post-milestone fix pass.
